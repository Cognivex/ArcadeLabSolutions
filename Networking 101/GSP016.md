### Run in Cloud Shell

1. Open **Cloud Shell** from the top right navigation bar in the Google Cloud Console.
2. Download, grant execution permissions, and run the script:

```bash
curl -LO https://raw.githubusercontent.com/Cognivex/ArcadeLabSolutions/refs/heads/main/Networking%20101/gsp016.sh
chmod +x gsp016.sh
./gsp016.sh
```
