## Execution Guide

### Step 1: Open Google Cloud Shell

1. Log in to the [Google Cloud Console](https://console.cloud.google.com) using your incognito student credentials.
2. Click the **Activate Cloud Shell** icon (`>_`) in the top-right toolbar.

### Step 2: Download and Execute the Automation Script

Run the following commands in Cloud Shell:

```bash
curl -LO https://raw.githubusercontent.com/Cognivex/ArcadeLabSolutions/refs/heads/main/Set%20Up%20a%20Google%20Cloud%20Network%20Challenge%20Lab/gsp314.sh
chmod +x gsp314.sh
./gsp314.sh
```
